## How this course works

<CardGrid>
  <Card title="Wire-first, always" icon="seti:json">
    Every concept starts from the JSON-RPC messages actually exchanged — then shows how the TypeScript and Python SDKs generate them, so nothing is magic.
  </Card>
  <Card title="Two SDKs side by side" icon="seti:config">
    Server and client examples in TypeScript (`@modelcontextprotocol/server`, `@modelcontextprotocol/client`) and Python (`mcp`) through synced tabs — pick one and follow it everywhere.
  </Card>
  <Card title="Design, not just syntax" icon="approve-check">
    Why the protocol is stateless, when a tool beats a resource, how to shape tools for agents, how to keep a remote server secure — trade-offs on every page.
  </Card>
  <Card title="Current spec, with history" icon="puzzle">
    Written against protocol revision 2026-07-28, with clearly labelled notes on the legacy era (2025-11-25 and earlier) so older tutorials still make sense. Bilingual (English / ไทย) with saved quiz progress.
  </Card>
</CardGrid>
