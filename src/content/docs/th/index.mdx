## คอร์สนี้ทำงานยังไง

<CardGrid>
  <Card title="Wire-first เสมอ" icon="seti:json">
    ทุกแนวคิดเริ่มจาก JSON-RPC message ที่ส่งกันจริงบน wire แล้วค่อยแสดงว่า SDK ของ TypeScript และ Python generate มันออกมาอย่างไร จะได้ไม่มีอะไรเป็น magic
  </Card>
  <Card title="สอง SDK เทียบกันชัด ๆ" icon="seti:config">
    ตัวอย่าง server และ client ใน TypeScript (`@modelcontextprotocol/server`, `@modelcontextprotocol/client`) และ Python (`mcp`) ผ่านแท็บที่ sync กัน เลือกภาษาครั้งเดียวแล้วตามไปทุกที่
  </Card>
  <Card title="เน้นการออกแบบ ไม่ใช่แค่ syntax" icon="approve-check">
    ทำไม protocol ถึง stateless, เมื่อไร tool ดีกว่า resource, ออกแบบ tool ให้ agent ใช้ได้ดีอย่างไร, ทำให้ remote server ปลอดภัยอย่างไร — มี trade-off ให้คิดทุกหน้า
  </Card>
  <Card title="spec ปัจจุบัน พร้อมประวัติ" icon="puzzle">

  </Card>
